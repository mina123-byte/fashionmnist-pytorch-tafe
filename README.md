# FashionMNIST PyTorch Training Project

## Project Overview
Image classification using PyTorch and the FashionMNIST dataset.

## Features
- Neural network using nn.Module
- CPU and CUDA GPU support
- Training and evaluation
- SGD and Adam optimisers
- Model saving and loading
- Training checkpoints
- CSV experiment tracking

## Installation
pip install -r requirements.txt

## Run Training
python train.py

## Dataset
FashionMNIST: 60,000 training and 10,000 test images.

## Experiment Tracking
Training results are saved as CSV files in the results folder.
